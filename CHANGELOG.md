## [v0.5.0] - 2026-10-31

### Highlights

- Read a Google Doc's suggested edits and any file's comments
- Opt-in upload and update tools, off by default, confined to an upload root, and audit-logged
- Deny-by-default tool authorization with `drive:read` and `drive:write` scopes

### Added

- `get_document_suggestions`: a Google Doc's text split into original, inserted, and deleted segments by suggested edits, with each block's original and accepted text ([`107042d`](https://github.com/plexusone/mcp-google/commit/107042d))
- Drive skill with `get_file_comments`: comments on any file with quoted text, resolved state, and replies ([`f3434e3`](https://github.com/plexusone/mcp-google/commit/f3434e3))
- `upload_file` and `update_file`: upload or replace a Drive file, optionally converting it to a Doc, Sheet, or Slides file, registered only with `--enable-write` ([`a971b1b`](https://github.com/plexusone/mcp-google/commit/a971b1b))
- `--enable-write` / `MCP_GOOGLE_ENABLE_WRITE` and `--upload-root` / `MCP_GOOGLE_UPLOAD_ROOT`; write mode also requests the `drive.file` Google scope ([`62263a6`](https://github.com/plexusone/mcp-google/commit/62263a6))
- An explicit `--enable-write=false` on the command line wins over `MCP_GOOGLE_ENABLE_WRITE=true` ([`bda28dd`](https://github.com/plexusone/mcp-google/commit/bda28dd))
- Write tools refuse a parameter of the wrong type as `invalid_request`, name the targeted Drive file in the audit record, and read file IDs only from `drive.google.com` and `docs.google.com` links ([`85fec38`](https://github.com/plexusone/mcp-google/commit/85fec38))
- Write tools confine local paths to the upload root (including symbolic links) with oscompat, refuse files over 50 MB, return `{code,message}` errors, and audit-log every call ([`a971b1b`](https://github.com/plexusone/mcp-google/commit/a971b1b))
- `drive:read` and `drive:write` policy scopes ([`62263a6`](https://github.com/plexusone/mcp-google/commit/62263a6))
- CLI commands `get-document-suggestions`, `get-file-comments`, `upload-file`, and `update-file` ([`da2a8a3`](https://github.com/plexusone/mcp-google/commit/da2a8a3))
- Authorization through an explicit tool-to-scope table; a tool with no entry is denied when a token carries a scope claim ([`70eb67b`](https://github.com/plexusone/mcp-google/commit/70eb67b))

### Changed

- Docs, Sheets, and Slides skills call gogoogle instead of building Google API clients; a test fails on any direct client use ([`d00aa63`](https://github.com/plexusone/mcp-google/commit/d00aa63))
- Upgrade `github.com/grokify/gogoogle` from v0.11.1 to v0.14.0 and add `github.com/grokify/oscompat` v0.11.0 ([`eff47c9`](https://github.com/plexusone/mcp-google/commit/eff47c9))
- Write tools open each file once, through oscompat's confined open, check the handle, and stream it to Drive with the read capped at the size limit, so a link swapped in after the check is never followed and a file that grows is refused as `file_too_large` ([`152dc27`](https://github.com/plexusone/mcp-google/commit/152dc27))
- Upgrade `google.golang.org/api` to v0.310.0 ([`8959804`](https://github.com/plexusone/mcp-google/commit/8959804))

### Documentation

- Add the tools reference for Drive and suggestions, write-mode configuration and scope documentation, and v0.5.0 release notes
- Describe the per-tool scope map and deny-unmapped behavior ([`e297661`](https://github.com/plexusone/mcp-google/commit/e297661))
- State the scope-less token rule, the `drive.file` limits, and the implemented roadmap items ([`78f77c7`](https://github.com/plexusone/mcp-google/commit/78f77c7))
- Describe the single confined open, the link rules, the accepted file links, and oscompat as a dependency ([`8f9152c`](https://github.com/plexusone/mcp-google/commit/8f9152c))

### Tests

- Guard that fails if a skill imports API client options, builds an API service, or finishes a request itself, and fake-API tests for every skill ([`ec71d0b`](https://github.com/plexusone/mcp-google/commit/ec71d0b))
- Every registered tool has exactly one scope mapping, including the write tools ([`1812cbf`](https://github.com/plexusone/mcp-google/commit/1812cbf))
- Write mode: confinement, error codes, audit records, scopes, and an MCP round trip ([`04040ad`](https://github.com/plexusone/mcp-google/commit/04040ad))
- Write mode: a file that grows past the limit, a link swapped in after the open, and links with absolute and relative targets ([`0b047e6`](https://github.com/plexusone/mcp-google/commit/0b047e6))
- Close assertion gaps: the audit log never holds the upload root, a denied call never reaches the next handler, write scopes keep every default scope, scope pins for the new tools, and the guard flags every `.Do` call ([`4eb4d75`](https://github.com/plexusone/mcp-google/commit/4eb4d75))

## [v0.4.0] - 2026-08-09

### Highlights

- Streamable-HTTP transport secured by ID-JAG (Enterprise-Managed Authorization) resource-server verification

### Added

- `serve --http` / `MCP_GOOGLE_HTTP_ADDR`: opt-in streamable-HTTP transport (stdio remains the default) ([`d634f26`](https://github.com/plexusone/mcp-google/commit/d634f26))
- `--idjag-issuer`, `--idjag-audience`, `--idjag-jwks-url` flags: verify bearer JWTs as a pure OAuth resource server via the agent-protocols ID-JAG adapter ([`d634f26`](https://github.com/plexusone/mcp-google/commit/d634f26))
- `internal/emauth` middleware: audit-logs the verified identity (sub, act chain, scope) on every tool call and gates tools by scope (`docs:read`, `sheets:read`, `slides:read`) ([`d634f26`](https://github.com/plexusone/mcp-google/commit/d634f26))
- Skills now report a `Version()` (docs, sheets, slides all at v0.5.0) ([`76528ce`](https://github.com/plexusone/mcp-google/commit/76528ce))

### Changed

- Upgrade `omniskill` from v0.10.0 to v0.12.0, adding the external resource-server auth support the HTTP transport depends on ([`e0995d0`](https://github.com/plexusone/mcp-google/commit/e0995d0))
- Upgrade `google.golang.org/api` from v0.282.0 to v0.292.0 ([`e0995d0`](https://github.com/plexusone/mcp-google/commit/e0995d0))
- Upgrade `github.com/modelcontextprotocol/go-sdk` to v1.7.0 ([`ffacab6`](https://github.com/plexusone/mcp-google/commit/ffacab6))
- Require Go 1.26.4 ([`e0995d0`](https://github.com/plexusone/mcp-google/commit/e0995d0))

### Fixed

- Auth: avoid a panic from `omnitoken.NewFromCredentials(name, nil)` when initializing the service-account token manager ([`40c7398`](https://github.com/plexusone/mcp-google/commit/40c7398))

### Documentation

- Add v0.4.0 release notes and HTTP transport / ID-JAG configuration guide
- Update README shields ([`56f834e`](https://github.com/plexusone/mcp-google/commit/56f834e))
